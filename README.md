# SEC CERT TEST

**SEC CERT TEST** is an open-source web application for practicing cybersecurity certification exams.

The goal of this project is to create a simple and modern platform where anyone can practice, prepare, and test their knowledge before taking cybersecurity certification exams.

## Current Development

The project is currently focused on building the **ISC2 Certified in Cybersecurity (CC)** exam system.

We are currently working on:

* Migrating and organizing the ISC2 CC question bank
* Separating questions into certification domains
* Building Practice Mode
* Building Exam Simulation Mode
* Question randomization
* Exam timer
* Answer explanations
* Results and performance tracking
* English / Thai language support

## What SEC CERT TEST Can Do

### Practice Mode

Practice at your own pace.

* Select specific domains
* Choose the number of questions
* No time limit
* Randomized questions
* Review answers and explanations

### Exam Mode

Simulate a certification exam experience.

* 125-question exam simulation
* Timed exam
* Randomized questions
* Questions distributed across exam domains
* Exam-style interface
* Final score and performance summary

## Certification Support

Currently supported:

**ISC2 Certified in Cybersecurity (CC)**

* English
* Thai

The project structure is designed to support additional cybersecurity certifications in the future.
