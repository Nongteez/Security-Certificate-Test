EN: A knowledge factor uses a secret the claimant knows, such as a password or PIN. A possession factor demonstrates control of an authenticator, such as a registered hardware security key; simply carrying an unrelated object is not authentication evidence. An inherence factor uses a biometric characteristic such as a fingerprint. For NIST digital authentication, a biometric is not a standalone authenticator: it is used with a physical authenticator, for example to activate a security key. That combines possession with inherence. Possession can be compromised without physically stealing a device, and biometrics are neither unforgeable nor a guarantee of correct identification. Factor choice reduces particular risks; it does not remove all risk.
TH: Knowledge factor ใช้ความลับที่ผู้ร้องขอรู้ เช่น รหัสผ่านหรือ PIN ส่วน Possession factor แสดงการควบคุมเครื่องมือยืนยันตัวตน เช่น Hardware security key ที่ลงทะเบียนไว้ การพกสิ่งของที่ไม่เกี่ยวข้องไม่ใช่หลักฐานยืนยันตัวตน Inherence factor ใช้ลักษณะทางชีวมิติ เช่น ลายนิ้วมือ สำหรับการยืนยันตัวตนดิจิทัลตาม NIST ชีวมิติไม่ใช่เครื่องมือยืนยันตัวตนที่ใช้เดี่ยว ๆ แต่ใช้ร่วมกับเครื่องมือทางกายภาพ เช่น ใช้ลายนิ้วมือเปิดใช้งาน Security key จึงรวม Possession กับ Inherence เข้าด้วยกัน ปัจจัยสิ่งที่มีอาจถูกโจมตีได้โดยไม่ต้องขโมยอุปกรณ์จริง และชีวมิติไม่ได้ปลอมแปลงไม่ได้หรือรับประกันการระบุตัวตนถูกต้องเสมอ การเลือกปัจจัยช่วยลดความเสี่ยงบางแบบ ไม่ได้ขจัดความเสี่ยงทั้งหมด
EN: MFA requires at least two distinct factor types. 2FA is the two-factor case.

TH: แค่นี้ยังไม่ใช่ MFA

EN: A password followed by a PIN remains knowledge-only even if two screens are involved. A password plus a successful challenge to a registered security key combines knowledge and possession and can provide MFA. The system must actually verify the factors; merely owning a key is insufficient. Location, IP address and device signals can inform risk-based access decisions, but an office IP is not a second independent authentication factor in this lesson’s three-category model. One physical device can support multiple factors, such as a security key requiring a biometric activation step. Conversely, multiple devices do not automatically mean multiple factor types. MFA reduces the risk from a compromised single factor; it does not promise immunity to phishing or session theft.
TH: รหัสผ่านตามด้วย PIN ยังเป็นปัจจัยความรู้เพียงประเภทเดียว แม้จะมีสองหน้าจอ รหัสผ่านร่วมกับการตอบ Challenge สำเร็จจาก Security key ที่ลงทะเบียนผูกกับบัญชีรวม Knowledge กับ Possession และเป็น MFA ได้ ระบบต้องตรวจปัจจัยจริง การมี Security key อยู่เฉย ๆ ไม่พอ ตำแหน่ง IP address และสัญญาณอุปกรณ์อาจใช้ประกอบการตัดสินความเสี่ยงในการเข้าถึง แต่ IP สำนักงานไม่ใช่ปัจจัยยืนยันตัวตนอิสระประเภทที่สองตามแบบจำลองสามประเภทในบทเรียนนี้ อุปกรณ์จริงหนึ่งชิ้นอาจรองรับหลายปัจจัย เช่น Security key ที่ต้องใช้ชีวมิติเปิดใช้งาน ในทางกลับกัน หลายอุปกรณ์ไม่ได้แปลว่ามีปัจจัยต่างประเภทโดยอัตโนมัติ MFA ลดความเสี่ยงจากปัจจัยเดียวที่ถูกโจมตี แต่ไม่รับประกันว่าจะต้านทาน Phishing หรือการขโมยเซสชันได้ทั้งหมด
EN: Two secrets ≠ two factors. A location rule can add protection without being MFA.
TH: สองความลับ ≠ สองปัจจัย กฎตำแหน่งเพิ่มการป้องกันได้ โดยไม่จำเป็นต้องเป็น MFA
