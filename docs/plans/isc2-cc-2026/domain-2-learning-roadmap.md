## 3. Visual Pedagogy & Bilingual Teaching Design System

### 3.1 Visual Pedagogy Rules (Derived from Read-Only Audit of Domain 1)
1. **No Forced Diagrams:** Not every concept should be forced into a custom SVG diagram. Where a concept is best understood through a **clean comparison table** (`D2-L01-S5`, `D2-L04-S8`, `D2-L05-S4`, `D2-L07-S7`, `D2-L08-S5`), a **realistic worked artifact** (`D2-L02-S5` Risk Register record, `D2-L08-S3` Security Scorecard table), or a **structured memory matrix** (`D2-L08-S6` Exam Memory Aid), we use structured comparison/table layouts instead of decorative diagrams.
2. **Concept-Specific Visual Relationships When Diagrams Are Used:**
   - **3-Pillar Architecture (`pillars` / `diagram`):** Used for `GRC` (`D2-L01-S1`) and `Awareness + Culture + Leadership` (`D2-L05-S6`).
   - **Timeline & Threshold Visuals (`incident-flow` / `diagram`):** Used for `Contain → Assess → Notify` (`D2-L04-S3`) and the `RPO` (backward to last backup) vs. `RTO` (forward to recovery target) timeline (`D2-L04-S4`).
   - **Contrast Split Boards (`comparison`):** Used for `With GRC (7 Benefits) vs. Without GRC (4 Failures)` (`D2-L01-S3`), `Qualitative/Ordinal vs. Quantitative Scoring` (`D2-L02-S4`), and `KRI (Early Warning) vs. KPI (Target Achievement)` (`D2-L07-S7`).
3. **Viewport Budget (`1920×1080` & `1366×768`):**
   - Clean white/near-white surfaces (`#ffffff` / `#f8fafc`), dark navy/slate typography (`#0f172a` / `#334155`), restrained blue accents (`#1d4ed8` / `#2563eb`), and semantic status badges (`#15803d` green, `#b45309` amber, `#b91c1c` red).
   - Maximum 3–4 visual groups per slide canvas so `1366×768` never clips or requires nested scrolling; exhaustive lists (such as all 11 Risk Register fields on `D2-L02-S3` or all 8 BCP elements on `D2-L03-S3`) are grouped into 3–4 logical clusters on the main canvas and unpacked line-by-line in **Reading Mode (`explanationBlocks`)**.

### 3.2 Bilingual TH/EN Voice Contract
- **TH Mode (`th`):** Follows the exact pedagogical voice of `Domain 2.md` and `D2 sum.md` — natural, clear Thai prose that retains standard English cybersecurity terms (`Governance`, `Risk Register`, `Residual Risk`, `BCP`, `DRP`, `BIA`, `RTO`, `RPO`, `Phishing`, `Whaling`, `Vishing`, `Pretexting`, `MFA`, `KPI`, `KRI`, `Dashboard`, `Scorecard`) in parentheses or inline where Thai practitioners naturally use them. Avoids awkward literal machine translations and allowlists natural Thai compounds containing `"รอ"` (e.g., `กรอก`, `รองรับ`, `ครอบคลุม`, `ร่องรอย`, `รอบคอบ`, `ต่อรอง`, `รับรอง`, `สำรอง`) so they are never misflagged as placeholders.
- **EN Mode (`en`):** Crisp, beginner-accessible professional English aligned with ISC2 CC exam phrasing.
- **Reading Mode (`lesson-info.js` Modal):** Every slide includes rich bilingual `explanationBlocks` (`text`, `list`, `table`) that go deeper than the main slide canvas, plus explicit exam trap callouts (`Domain 2.md` §24) and source quarantine notes (`D2-Q01`–`D2-Q06`) where applicable.
