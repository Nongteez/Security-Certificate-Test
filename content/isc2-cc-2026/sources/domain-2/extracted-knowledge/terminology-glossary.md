## Caption normalization rules

Normalize only with a recorded basis: coit -> COBIT (S07/R-COBIT); corrupted ISO designation -> ISO/IEC 27001 (S07/R-ISO); compliance breaking -> tracking (S08); HIPPA -> HIPAA (S17/R-HHS); hard site -> hot site (S18/R-DR); phishing variants -> legible S25/S26 plus R-SOCIAL; paged/unpaged -> patched/unpatched where S30-S33 explicitly corroborate the intended metric. These are editorial display choices, not changes to original files or claims that every spoken word is known. PHI's Protected expansion is an explicit external correction, not merely spelling cleanup. No fixed corrected text is asserted for the incomplete warm-site sentence or disputed scorecard units.
