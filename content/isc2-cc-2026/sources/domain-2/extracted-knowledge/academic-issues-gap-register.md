# Domain 2 - Academic Issues Gap Register

## Issue-state meaning and result

Issue-resolution labels below are evidence-tracking states, separate from canonical curation labels. RESOLVED closes only its stated scope; PARTIALLY_RESOLVED records an independently supported clarification without erasing other uncertainty; UNRESOLVED retains a hold. No label means academically approved.

**14 carried Phase 1 issues: 1 RESOLVED (exclusion scope only), 5 PARTIALLY_RESOLVED, 8 UNRESOLVED.** All 14 Phase 1 IDs are preserved. Raw sources and Phase 1 reports are unchanged. The Phase 3 reviewer must accept/reject proposed corrections and approve translations; this phase never silently repairs evidence.

## Retrieval limitations and provenance

EUR-Lex HTML/PDF access returned a JavaScript/robot challenge; no statutory text was accepted from those pages. CISA's strong-password URL returned 403, so NIST authentication guidance was used for the limited password-manager/phishing-resistance checks. The candidate YouTube URL returned a cache-miss error and did not authenticate the course. No unavailable page was represented as read. No source was redistributed, downloaded into the raw source directory, renamed, normalized or removed.

Source confidence remains distinct from academic correctness. Authority references validate only the specified terminology/scope; they do not reveal the instructor's intended missing unit, unspoken clause or unseen slide. A source-specific conflict cannot be closed by substituting a different authoritative example.
