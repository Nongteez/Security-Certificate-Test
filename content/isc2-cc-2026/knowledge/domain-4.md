## 1. Domain Overview & Topic Coverage

This domain covers foundational networking architecture, threat mitigation, segmentation, wireless, IoT/OT security, and cloud computing principles.

> [!CAUTION]
> **Numbered Objective Status:**
> The official ISC2 numbered breakdown (e.g., `4.1`, `4.2`) for Domain 4 has not been independently verified. To maintain strict documentation integrity, no numbered IDs are fabricated. Staged entries should record `4.X — Pending Verification` until the official syllabus numbering is confirmed.

### Confirmed Topic Scope
- **Topic 4.A — Computer Networking Fundamentals:** OSI Model (7 layers, protocols, encapsulation), TCP/IP Model (4 layers), IPv4 vs. IPv6, VPNs (IPsec, SSL/TLS, remote access, site-to-site).
- **Topic 4.B — Network Threats and Prevention:** Firewalls (Packet filtering, Stateful, NGFW), IDS vs. IPS, Network traffic monitoring, and packet inspection.
- **Topic 4.C — Network Security Architecture:** Network segmentation, VLANs, micro-segmentation, Defense in Depth, Zero Trust Architecture ("never trust, always verify", "assume breach").
- **Topic 4.D — Wireless Networks:** Wireless security standards, WPA2/WPA3 encryption, rogue access points, evil twins, and wireless attacks.
- **Topic 4.E — Embedded Systems & Emerging Technologies:** Internet of Things (IoT) security, Industrial Control Systems (ICS) / SCADA security challenges.
- **Topic 4.F — Cloud Security Concepts:** Essential cloud characteristics (NIST SP 800-145), service models (IaaS, PaaS, SaaS), deployment models (Public, Private, Hybrid, Community), and the Shared Responsibility Model.
