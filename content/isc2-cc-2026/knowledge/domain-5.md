## 1. Domain Overview & Verified Objectives

This domain addresses data lifecycle security, cryptography, logging, telemetry, threat intelligence, incident response phases, asset protection, and security testing exercises.

### Official Learning Objectives
- **Objective 5.1:** Understand data security (Data lifecycle, classification, labeling, masking, sanitization per NIST SP 800-88, symmetric/asymmetric cryptography, hashing, quantum-resistant concepts)
- **Objective 5.2:** Understand security operations (Logging, telemetry, event triage, threat actors, cyber threat intelligence [CTI], MITRE ATT&CK, Cyber Kill Chain)
- **Objective 5.3:** Understand Incident Response (IR) (Data handling policies, Incident Response Plan [IRP], IR lifecycle phases, tabletop exercises)
- **Objective 5.4:** Understand asset protection (Asset lifecycle, EOL/EOS software & hardware management, configuration and change management)
- **Objective 5.5:** Understand security testing (Blue Teaming defensive posture, Red Teaming adversarial simulation, Purple Teaming collaborative validation)
